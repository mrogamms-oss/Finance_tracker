# 💰 Finance Tracker

My first Python project.

A simple terminal-based finance tracker that calculates a user's remaining balance after expenses and optionally saves the information into a JSON file.

## Features

- Calculate balance
- Save data as JSON
- Record current date and time
- Personalized messages
- Basic input validation

## Technologies Used

- Python 3
- JSON
- datetime

## How to Run

Clone the repository.

```bash
git clone <repository-url>
```

Enter the folder.

```bash
cd Finance_tracker
```

Run the program.

```bash
python3 main.py
```
